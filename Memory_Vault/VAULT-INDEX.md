# VAULT INDEX

This vault is JARVIS's persistent external memory. Load only the notes relevant to the current task.

## Memory rules
- This vault is the long-term source of truth for durable Jarvis memory.
- Do not invent memories.
- Prefer updating an existing note over creating duplicates.
- Important project findings belong in the relevant project note.
- Daily activity belongs in the current daily note.
- User-requested memories should be written immediately.

## Vault structure
- `01 - Daily Notes/` — chronological session/activity log
- `02 - Profile/` — durable information about the user and working preferences
- `03 - Projects/` — persistent project knowledge and findings
- `04 - Knowledge/` — reusable technical/reference knowledge
- `05 - Jobs/` — task-specific procedures and priming notes

## Project workspace
The active local project workspace is separate from this vault. Jarvis may use it for files, tools, firmware, source, extraction output, and experiments.
